## Implemented behavior

The Forge side now registers a server owned follow lease manager and a reusable marked stick item. The marker stores a namespaced version, issued session identifier, and owner reference. The server validates the operator, marker, held hand, live `Mob` target, dimension, range, interaction deduplication, one owner and one target arbitration, and the thirty two lease cap before claiming.

The lease uses a controller adapter every ten ticks. Ordinary mobs use normal navigation. SmartBrainLib entities use a temporary `WALK_TARGET` memory and restore the prior target only when the lease still owns that memory. It does not teleport the target or set direct velocity. Arrival, timeout, blocked progress, range, marker loss, permission loss, death, removal, logout, dimension change, unload, shutdown, and explicit stop release the lease and stop only its owned intent. Repeated interaction callbacks for the already claimed target are idempotent and keep the lease active. The issued marker remains reusable during the server session. Server shutdown clears issuance and lease state, so an old marker cannot claim after restart.

Follow diagnostics use the existing `bfs-debug-v2` writer. The category records claim, adapter, intent, progress, block, rejection, release, and restoration events with pseudonymous owner and target values. The parser validates the event fields and rejects raw UUID leakage.

## Security review

The scoped review found no confirmed exploitable finding. The command remains permission level two, interaction handling is server side, markers are bound to the current server issuance and owner, operator status is checked again during interaction and ticking, duplicate callbacks are deduplicated, and leases are bounded to 32 entries, 64 blocks, 2,400 ticks, and 200 blocked ticks. Follow diagnostics pseudonymize owner and target values. The parser tests reject raw UUID leakage. Residual risk is the unverified third party follow interaction, independent fixture, normal moving follow path, and restoration oracle.
