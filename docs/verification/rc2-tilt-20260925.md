# RC2 Tilt Command Verification

Verified September 25, 2026, on Minecraft 1.20.1 and Forge 47.2.0. This is a testing update to product version `1.0-rc.2-hotfix.1`, delivered as `bfs-1.0-rc.2-hotfix.1-tilt.jar`.

## Candidate

The JAR is 4,528,885 bytes. Its SHA 256 is `c5a18bb6f577c1683c3320278ca9902da82a3a75a4c0238354b695bb570d04a7`. The [manifest](artifacts/rc2-tilt-20260925/manifest.json) records SHA 512, dependency hashes, the baseline commit, changed Java source hashes, and screenshot hashes. The same artifact and dependency hashes were verified in the packaged server, actual deployed laptop client `build/mods`, and laptop Downloads. ZIP integrity and embedded version metadata passed.

## Automated verification

```sh
./gradlew :forge:test :forge:GameTestServer :forge:build \
  -PbfsGameTestNamespaces=bfstuning \
  -PbfsGameTestRunDir=run/bfs-tilt-20260925 --no-daemon
```

All 75 unit tests and all five required `bfstuning` GameTests passed. The build succeeded. The focused cases cover command parsing, wildcard and namespaced targets, reset, limits, zero turn rate, and actual controller travel during normal swimming and pursuit, in both vertical directions. Movement cases use base speed `2 2`, sprint multipliers `2 6`, and tilt limits `35 35` at 60 degrees per second. Existing tests also retain large speed and sprint value acceptance and movement coverage.

No resource data changed, and no formatter task is configured. `git diff --check` passed. This bounded update does not repeat the full gameplay suite or the unrelated long population test.

## Packaged multiplayer verification

The installed Forge dedicated server ran without a GUI on `node-1`. A uniquely owned Trident instance, `bfs_tilt_20260925`, ran on the `envision` laptop and joined the matching private server with authenticated multiplayer. The actual [client renderer](artifacts/rc2-tilt-20260925/renderer.png) was the NVIDIA GeForce RTX 5090 Laptop GPU. Java 17, GeckoLib 4.4.7, and SmartBrainLib 1.14.2 were used. Audio settings were unchanged.

The laptop issued `/bfs debug settilt oceanic_whitetip_shark 45 45 60`. The server accepted the command, and [client chat feedback](artifacts/rc2-tilt-20260925/tilt-command.png) displayed the angles, rate, supported species, and session lifetime. Console checks also verified an unquoted wildcard applying to ten supported species, `bfs:` namespaced readback showing session values, and tilt reset.

An Oceanic Whitetip naturally pursued stationary prey above and below it in a water fixture. The [upward view](artifacts/rc2-tilt-20260925/upward-verified.png) and [downward view](artifacts/rc2-tilt-20260925/downward-verified.png) show the synchronized body tilt. Sprint multipliers remained `2 6`. The close screenshots used base speed `0.5 0.5` to keep the moving shark in view; a separate run at base `2 2` produced observed server pitch values of approximately negative 35.86 and negative 45 degrees during ascent. Pitch was not assigned to manufacture the observed motion. The automated test covers both directions at base `2 2`.

These checks verify live tuning and client presentation, not a new guarantee about every species, terrain shape, or extreme speed. Existing route clearance remains in force. Untuned species retain their previous movement behavior.
