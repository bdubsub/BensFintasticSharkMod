# Phase 002 Task 004 Fish Presentation State Matrix

Date: September 9, 2026

Cod and Salmon Forge adapters now use pure presentation selectors for their live state matrices. Dead or dying entities stop the live controller. Cod then selects flop, fast swim, ordinary swim, or idle by water, synchronized fast flag, and movement. Salmon preserves exact case sensitive `Spin` preemption, then selects flop, fast swim, ordinary swim, or idle. The selector has no gameplay mutation and the existing server synchronized fast flag remains the single threshold authority.

The deterministic matrix tests cover dead priority, land and water transitions, fast and ordinary movement, stillness, exact `Spin` precedence, and the boundary flag without an implicit threshold shift.

The fish movement integrator now projects local forward input through the current body pitch before applying water travel. Direct-above and direct-below routes keep forward propulsion during the smooth pitch entry, then brake residual vertical velocity when forward input ends. The controller no longer writes a separate target vertical impulse, so a fish cannot translate vertically while its body remains level or acquire pitch while stationary.
