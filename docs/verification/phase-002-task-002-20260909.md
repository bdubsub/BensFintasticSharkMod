# Phase 002 Task 002 Transformer Characterization

Date: September 9, 2026

The animation baking interface is now targeted and fail closed. With no arguments, or with one animation directory, it processes only the phase-owned Cod, Salmon, and Oceanic Whitetip files. Explicit file arguments are accepted for controlled fixtures. The evaluator accepts numeric arithmetic, `math.sin`, `math.cos`, and `q.anim_time` or `query.anim_time` in degrees. Python evaluation and implicit builtins are not used. Unsupported names, attributes, calls, malformed vectors, invalid keyframe times, indeterminate lengths, and non-finite results raise before the source file is written.

The transformer keeps static numeric vectors and existing time-keyed maps unchanged, emits stable ascending time keys, preserves loop endpoints, and applies mutations only after every candidate channel has been evaluated successfully. A second run over baked output returns zero transformed channels and leaves the bytes unchanged.
